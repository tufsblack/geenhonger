# GeenHonger 1.0.0
Spelers krijgen nooit honger. Zet de plugin op je lobby-server en klaar.

- Eten blijft gewoon werken, maar het hongerbalkje daalt nooit.
- `config.yml`: `werelden` (leeg = alle werelden), `actief`, `uitzondering-permissie`.
- Permissie `geenhonger.honger`: die speler krijgt wel honger. `/geenhonger reload` herlaadt de config (permissie `geenhonger.admin`).
- Bouwen: upload alle bestanden naar GitHub, de workflow maakt `GeenHonger.jar`.
